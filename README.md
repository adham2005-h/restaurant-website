# موقع مطعم متعدد الصفحات

## التقنيات

HTML وCSS وJavaScript.

## فكرة المشروع

صفحات الرئيسية والقائمة والحجز والتواصل، مع تحقق المتصفح من الحقول وتنسيق للشاشات الصغيرة.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `index.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `contact.html`
- `index.html`
- `main.js`
- `menu.html`
- `reservation.html`
- `style.css`

## حدود المشروع

نماذج الحجز والتواصل تجريبية: لا تُرسل ولا تحفظ البيانات، وتوضح الرسالة ذلك. لا توجد خدمة حجز أو دفع.
