# Restaurant Website

A restaurant website with home, menu, reservation and contact pages. I used JavaScript for form interactions and CSS for the layout.

## Technologies

HTML, CSS, JavaScript.

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Keep the existing image and stylesheet folders in place.

## Project scope

Reservation and contact forms are front-end demonstrations; there is no booking, messaging or payment backend.
